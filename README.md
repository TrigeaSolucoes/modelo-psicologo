# Clarissa Viana Psicologia — site-modelo

Site-modelo **fictício** de Consultório de psicologia (adultos, presencial e online) em Juiz de Fora (MG), criado pela [Trígea Soluções](https://trigea.com.br/) para mostrar como pode ficar o site de um negócio desse ramo.
Negócio, pessoas, telefones e endereços são inventados.

Demonstração: https://trigeasolucoes.github.io/modelo-psicologo/
